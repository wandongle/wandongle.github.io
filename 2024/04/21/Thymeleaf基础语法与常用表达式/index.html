Thymeleaf 基础语法与常用表达式

发表于2024-04-21|更新于2026-09-15|java
|字数总计:1.7k|阅读时长:7分钟|阅读量:

Thymeleaf 的语法简单易懂，类似 HTML，但又具有更强大的功能。我们可以在模板中使用 Thymeleaf 表达式访问后端数据，并将其展示在页面中。此外，它还支持条件判断、循环和模板片段等功能，让页面展示更加灵活。

一、创建模板文件

在 HTML 根标签中声明 th 命名空间，即可使用以 th: 开头的 Thymeleaf 属性。

浏览器会将普通 HTML 正常显示；服务端的 Thymeleaf 模板引擎会处理 th: 属性，从而把后端数据渲染到页面中。

四、使用文本

1. th:text

th:text 会替换标签中的文本内容，并对其中的 HTML 标签进行转义。

2. th:utext

th:utext 与 th:text 的区别在于：th:utext 不会转义 HTML 标签。因此当 message = “Welcome to Beijing!“ 时：

  • th:utext 的结果：Welcome to Beijing!
  • th:text 的结果：Welcome to Beijing!

使用 th:utext 渲染外部输入时要注意 XSS 风险，确保内容可信或已经过清理。

六、条件判断

1. th:if

当表达式的结果为真时显示内容，否则不显示：

常见的判断规则如下：

  • 值为 null 时，结果为假。
  • 布尔值为 true 时，结果为真。
  • 数字非 0 时，结果为真。
  • 字符非 0 时，结果为真。
  • 字符串不是 “false”、”off” 或 “no” 时，结果为真。
  • 其他非空对象通常视为真。

2. th:unless

th:unless 与 th:if 相反：当表达式为假时显示内容。

3. th:switch 与 th:case

当 switch 表达式满足某个 case 时，才显示对应标签。

七、内联表达式

内联表达式允许我们直接在 HTML 文本中使用标准表达式，而不需要使用 th: 开头的标签属性。

1. [[…]]

[[…]] 相当于 th:text，会对 HTML 标签自动进行转义。

2. [(…)]

[(…)] 相当于 th:utext，不会对 HTML 标签进行转义。
